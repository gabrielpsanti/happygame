# HappyGame

Aplicação web social para gamers. Com ela você pode:
- Publicar posts, curtir, comentar e repostar
- Personalizar perfil (nome e foto)
- Ver jogos em destaque (a partir de um JSON local)
- Criar e gerenciar eventos pessoais

Tecnologias: Next.js 16, React 19 e Tailwind CSS 4. Persistência apenas no navegador via localStorage (não há backend ainda).

## Como instalar e rodar (desenvolvimento)

Pré‑requisitos:
- Node.js 20+ e npm 10+ (ou yarn/pnpm, se preferir)

Passos:
1. Instale as dependências:
   - npm install
2. Inicie o servidor de desenvolvimento:
   - npm run dev
3. Acesse no navegador:
   - http://localhost:3000
